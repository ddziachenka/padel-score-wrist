Support

Behöver du hjälp med Padel Score — Wrist? Mejla Dzmitry Dziachenka på dzmitry.dziachenka@gmail.com.

Utvecklaren svarar i mån av tid. Ingen svarstid garanteras.

1. Poängräkning och sparade spel

  • Tryckt fel? Använd Ångra på poängskärmen. För tidigare misstag öppnar du spelmenyn och använder rättningsfunktionerna.
  • Ett nytt set väntar: bekräfta serveordningen innan du registrerar nästa boll.
  • Appen stängdes: öppna den igen för att återgå till det sparade spelet. Ett felmeddelande vid sparning betyder att ändringen inte har sparats säkert. Frigör utrymme vid behov och försök igen.
  • Omgångens totalantal har nåtts: tryck på Klar för att behålla resultatet. Höj totalantalet bollar när du blir tillfrågad för att fortsätta spela.

Demo, Spela igen och historik

Nytt spel → Prova poängtavlan (finns även under Om) öppnar ett förinställt matchexempel. Märkningen Demo skiljer det från riktigt spel. Prova att lägga till en poäng, välja Ångra eller Återställ demo. Demon slutar efter ett game och påverkar inte sparade spel, historik, inställningar, köp eller antalet gratisspel.

På ditt senaste resultat öppnar Spela igen en ny spelinställning med samma regler och serveordning. Kontrollera vem som servar först och tryck sedan på Starta spel. Historik finns under Nytt spel, på resultatet och i spelmenyn. Där visas alla avslutade riktiga spel, med det senaste först och detaljerade resultat. Äldre poster kan bara läsas. Bara det senaste resultatet kan ändras eller återupptas. Historiken är gratis även efter gränsen på fem spel.

Om → Urtavla och Smart trave beskriver hur du lägger till genvägen på en kompatibel urtavla eller i Smart trave. Den öppnar appen utan att visa någon liveställning.

2. Köp

De första fem avslutade spelen är gratis. Därefter ger ett engångsköp för permanent åtkomst obegränsat antal spel. Ditt pågående spel, senaste resultat, hela den lokala historiken och demon är fortfarande tillgängliga. Det finns ingen återkommande betalning.

Om priset inte kan hämtas, kontrollera klockans internetanslutning och tryck på Försök igen under Åtkomst. Om du redan har betalat, öppna Om → Åtkomst → Återställ köp med samma Apple-konto. Vänta på att ett väntande köp godkänns. Skicka inte ditt lösenord eller dina betalningsuppgifter till supporten.

Begär återbetalning via Apples Rapportera ett problem. Utvecklaren kan inte återbetala köp från App Store.

3. Radera lokala data

Öppna Inställningar → Radera lokala data och bekräfta. Det tar bort det pågående spelet, hela historiken över avslutade spel och resultat, åtgärdshistoriken och spelinställningarna. Antalet avslutade gratisspel och App Store-köpet behålls. Lokala data kan gå förlorade om du avinstallerar appen eller byter klocka. Appen saknar överföring mellan klockor, molnsynkronisering, molnsäkerhetskopiering och återställning via utvecklaren.

4. Ta med det här i ditt mejl

  • Din Apple Watch-modell och watchOS-version.
  • Appversionen och byggnumret som visas under Om.
  • Vad du gjorde, vad du förväntade dig och vad som hände i stället.
  • Det exakta felmeddelandet och gärna en skärmbild om den hjälper.

Skicka bara det som behövs för att förklara problemet. Skicka aldrig lösenord, verifieringskoder eller betalkortsuppgifter.

5. Integritet

Supportmeddelanden används bara för att besvara ditt ärende och raderas inom 90 dagar efter att det avslutats, om inte en rättslig skyldighet eller pågående tvist kräver längre lagring. Läs integritetspolicyn för mer information.

iPhone

Öppna App Store på klockan och sök efter Padel Score — Wrist. Du kan också öppna Watch-appen på parkopplad iPhone, hitta appen under Tillgängliga appar och trycka på Installera. Använd samma Apple-konto för köp på båda enheterna. Öppna Åtkomst på klockan med internet efter köpet. Tryck vid behov på Återställ köp. Köp och återställning kräver internet; verifierad åtkomst fungerar sedan offline. Historik och antal gratismatcher finns lokalt på klockan och synkas inte till iPhone. Demos sparar inga resultat och använder inga gratismatcher.
