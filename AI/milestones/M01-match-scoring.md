# M01 — Match Scoring

**ID:** M01
**Status:** REVIEW
**Depends on:** M00
**Validation:** make milestone ID=M01
**Handoff:** AI/handoffs/M01-handoff.md

## Objective

Получить детерминированный счёт обычного матча и правильного подающего для каждого перехода.

## Scope

- Вход: закрыта H2 в PRODUCT. Реализовать только выбранную политику сета/тай-брейка; структура движка принимает эту политику явно и не предполагает её из примера прототипа.
- Value-модель очков, геймов, последовательности сетов, стадии deuce и четырёх ролей подачи; 0/15/30/40, AD, три подтверждённых режима 40:40.
- Автоматический переход гейма и сета по утверждённой политике; сколько угодно последовательных сетов, без best-of и автоматического завершения матча.
- Подача на весь гейм и правила на границах сета/тай-брейка, если выбран; явный service anchor для последующей ручной коррекции.
- Чистый переход state+command в результат или ошибку; никакой зависимости от SwiftUI, часов, файловой системы или StoreKit.

## Non-goals

- Экран игры, запись на диск, американо и коммерческая модель.
- Star Point и дополнительные режимы 40:40.

## Acceptance criteria

- [ ] Табличные тесты покрывают каждую сторону выигрыша гейма, немедленный golden point, первый AD/выигрыш и возврат к решающим 40:40 при одном преимуществе, многократные deuce при обычном AD.
- [ ] Граничные тесты проверяют завершение/незавершение сета и каждый переход подачи по выбранной H2; тай-брейк тестируется только если он входит в утверждённую политику.
- [ ] После любого числа выигранных сетов новый сет доступен, session остаётся active до ручного Finish.
- [ ] Невалидные score/stage/service состояния возвращают структурированную ошибку без частичной мутации; предыдущий snapshot не изменяется.
- [ ] Тесты проверяют наблюдаемое поведение и регрессии этого этапа; `make milestone ID=M01` проходит на clean `REVIEW` HEAD с обязательными тестами без failures/skips.

## Validation

`make milestone ID=M01`. Обязательные проверки и evidence выполняются в одной Builder-сессии.

## Handoff

Записать `AI/handoffs/M01-handoff.md` по компактному шаблону: полный SHA, точные команды, exit codes, UTC time, report paths, counts, известные ограничения и следующий шаг. После доказанного DONE остановиться.
