# M07 — Finish and Resume

**ID:** M07
**Status:** IN_PROGRESS
**Depends on:** M06
**Validation:** make milestone ID=M07
**Handoff:** AI/handoffs/M07-handoff.md

## Objective

Завершить игру с честным результатом и восстановить случайно завершённую последнюю сессию.

## Scope

- Ручной Finish при любом обычном счёте, подтверждение и summary; незавершённый сет показан отдельно от выигранных.
- Американо: summary при N, tie без лишнего розыгрыша, ранний Finish с пометкой played/total; корректный последний неполный serving block.
- Последний результат доступен на home; Resume возвращает ту же sessionID и undo history, Edit result использует M06.
- Добавить связку Finish → New game. Старт новой игры прекращает возможность Edit/Resume предыдущей, но оставляет её результат read-only; предыдущий результат заменяется только при завершении новой игры. Объяснить это до Start, без создания турнирной таблицы.
- Если цель N уже достигнута, Resume требует сначала изменить N/счёт или отменить завершавшее действие; обычное очко сверх цели не добавляется.
- Зафиксировать ровно одно событие завершения на sessionID для M08 usage policy; повторное завершение/Resume/правка не удваивают счётчик.
- Settings → Delete local data показывает удаляемые игровые данные и подтверждение; после успешного удаления — пустой стартовый экран. Apple entitlement не удаляется. Семантика trial окончательно подключается в M08 по H4.

## Non-goals

- Общий рейтинг, история всех матчей, sharing и статистика партнёров.
- Объявление победителя обычного матча по неутверждённому best-of.

## Acceptance criteria

- [ ] Finish при 0:0, посреди гейма, сразу после сета и при равенстве не теряет исходное состояние и корректно подписывает итог.
- [ ] Случайный Finish отменяется/продолжается до старта новой session; не создаются дубликаты и не расходуется повторно trial.
- [ ] При 18:14 из 32 показан завершённый раунд; при 16:16 показана ничья; ранний результат отличим от достигшего цели.
- [ ] Результат и возможность восстановления проверены после перезапуска и сбоя записи, кнопки доступны через VoiceOver.
- [ ] После новой игры старый результат остаётся read-only до следующего Finish; локальное удаление и отмена его подтверждения работают атомарно.
- [ ] Правка N до текущей суммы явно подтверждает завершение; увеличение N в завершённой игре требует отдельного Resume, а N ниже суммы не сохраняется.
- [ ] Тесты проверяют наблюдаемое поведение и регрессии этого этапа; `make milestone ID=M07` проходит на clean `REVIEW` HEAD с обязательными тестами без failures/skips.
