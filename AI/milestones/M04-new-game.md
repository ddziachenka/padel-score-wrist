# M04 — New Game

**ID:** M04
**Status:** PLANNED
**Depends on:** M03
**Validation:** make milestone ID=M04
**Handoff:** AI/handoffs/M04-handoff.md

## Objective

Дать пользователю создать любой из двух форматов на часах с понятными правилами и подачей.

## Scope

- Английский стартовый экран и выбор Match/Americano, отдельные короткие редакторы параметров из DESIGN.
- Матч: одно из трёх deuce rules и очередь/начальный подающий. Американо: Total rallies, Rallies per server и очередь/первый подающий.
- Роли You/Partner/Opponent 1/Opponent 2 без обязательных имён; вспомогательный показ полного порядка четырёх игроков.
- Повтор последних валидных настроек с обзором перед Start; первый запуск ничего не восстанавливает из несуществовавшей истории.
- Черновик не меняет активную игру. При наличии игры доступно Resume; перезапись активной игры запрещена. Связку Finish → New game добавляет M07, когда появится экран завершения. Старт зависит от единого access interface, окончательная политика добавляется M08.
- Crown изменяет только выбранное числовое поле, локализуемые подписи и validation; доступность на выбранном самом маленьком размере.
- Добавить оригинальную иконку приложения и общие семантические color/typography assets в стиле DESIGN; ресурс включён в правильный Watch target и корректен на устройстве.

## Non-goals

- Турнирная настройка, ввод обязательных профилей, определение победителя розыгрыша.
- Покупка и paywall.

## Acceptance criteria

- [ ] Оба формата создаются независимо на Watch; количество сетов нигде не запрашивается.
- [ ] Ошибочные числа и service order объясняются у соответствующего поля и не создают session; Back отменяет draft.
- [ ] VoiceOver произносит смысл, значение и доступные действия; Crown не начисляет очки.
- [ ] Проверены первый запуск, повторный запуск, существующая session и ошибки записи; всё видимое содержимое английское и вынесено в ресурсы.
- [ ] Тесты проверяют наблюдаемое поведение и регрессии этого этапа; `make milestone ID=M04` проходит на clean `REVIEW` HEAD с обязательными тестами без failures/skips.

## Validation

`make milestone ID=M04`. Обязательные проверки и evidence выполняются в одной Builder-сессии.

## Handoff

Записать `AI/handoffs/M04-handoff.md` по компактному шаблону: полный SHA, точные команды, exit codes, UTC time, report paths, counts, известные ограничения и следующий шаг. После доказанного DONE остановиться.
