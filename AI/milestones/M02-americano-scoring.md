# M02 — Americano Scoring

**ID:** M02
**Status:** DONE
**Depends on:** M01
**Validation:** make milestone ID=M02
**Handoff:** AI/handoffs/M02-handoff.md

## Objective

Считать один раунд американо по общей сумме розыгрышей с точной очередью серий подачи.

## Scope

- Общие N розыгрышей и B розыгрышей в серии одного игрока: положительные целые, задаваемые пользователем; без предустановленного обязательного значения.
- Две суммы очков, оставшиеся N−(ours+theirs), service order четырёх ролей, конкретный подающий и номер следующего розыгрыша в серии.
- Предложенный контракт PRODUCT: достижение N открывает завершение раунда, допускается равный счёт и последняя неполная серия; команды начисления после N отвергаются до исправления.
- Поддержать валидируемую коррекцию score/N/B/anchor в доменной модели, не восстанавливая вымышленную историю по итоговым числам.

## Non-goals

- Организация турнира, ротация пар между матчами и суммарный рейтинг.
- Автоматическое продление до преимущества в два очка.

## Acceptance criteria

- [x] При N=32 и счёте 18:14 раунд достигает общей цели; команда не обязана набрать 32 сама. Эти числа — тестовые фикстуры, не продуктовые ограничения.
- [x] При B=4 роли сменяются через каждые четыре записанных розыгрыша вне зависимости от выигравшей команды; после четвёртой роли цикл повторяется.
- [x] Тесты покрывают B=1, N<B, N не кратное B, ничью, последний розыгрыш, перестановку очереди и ручной anchor.
- [x] N ниже уже сыгранной суммы и некорректный номер в серии не применяются; valid corrections не меняют команды и sessionID.
- [x] Тесты проверяют наблюдаемое поведение и регрессии этого этапа; `make milestone ID=M02` проходит на clean `REVIEW` HEAD с обязательными тестами без failures/skips.

## Validation

`make milestone ID=M02`. Обязательные проверки и evidence выполняются в одной Builder-сессии.
