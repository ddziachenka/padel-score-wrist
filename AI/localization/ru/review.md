## Glossary and voice

- Match → матч; generic game/session → игра; game within a set → гейм.
- Set → сет; rally → розыгрыш; point → очко.
- Server → подающий; serving → подача; service order → порядок подачи.
- Advantage → преимущество; One advantage → одно преимущество; Golden point → золотое очко.
- Deuce → «ровно»; tie-break → тай-брейк; Americano → американо.
- US / THEM → МЫ / ОНИ; spoken forms → мы / они, наша команда / соперники.
- Partner → партнёр; You → Вы; Opponent → соперник.
- Undo → отменить действие; Undo history → действия для отмены (available prior actions, never a log of past cancellations).
- Smart Stack → Смарт-стопка; Apple Account → Аккаунт Apple.
- Access → Доступ; Lifetime unlock → бессрочный доступ; purchase → разовая покупка бессрочного доступа. The CTA «Открыть навсегда» stays a short action label.

Respectful neutral Russian, clear verbs and concise watch labels. Instructions use plural polite imperatives without unnecessary formalities. Brand names and the conventional score AD remain unchanged with explicit reasons in unchanged.json. Full accessibility messages keep their explanatory detail.

- “%@ first” → «Сначала: %@» avoids gender disagreement with role labels.

- Demo “one game” is «один гейм»; “five completed games” remains «пять завершённых игр».
- Early finish says a team was ahead; it does not award a win. Americano totals explicitly combine both teams. Match is manually finished with no invented automatic overall winner.
